Сканнер секретов в конфигурациях CI/CD

cicd_secret_scanner/
├── Конфигурация (pyproject.toml, .gitignore)
├── src/scanner/          # Исходный код (основная логика)
│   ├── core/             # Ядро: модели и интерфейсы
│   ├── parsers/          # Парсеры CI/CD файлов
│   ├── detectors/        # Детекторы секретов
│   └── reporters/        # Вывод результатов
├── tests/                # Тесты
└── configs/              # Конфигурационные файлы

- src/scanner/core/
    - models.py — "Что мы сканируем и что находим". Здесь описаны классы данных, которые передаются между модулями.
      - RiskLevel - Уровень риска 1 файндинга
      - PipelineContext -  Хранит контекст переменной: где она используется. Это нужно для оценки риска: секрет в production опаснее, чем в test.
      - Finding - Каждый найденный потенциальный секрет — объект Finding
      - ScanResult - Содержит сводку: сколько критических уязвимостей, сколько всего и т.д.
    - interfaces.py — Здесь определены абстрактные базовые классы. Любой парсер/детектор/репортёр должен реализовать определённые методы.
- src/scanner/parsers/ - читаем CICD файлы
  - base.py - шаблон для парсеров
    - Mixin — вспомогательный класс, чтобы не дублировать код.
- src/scanner/detectors/ - ищем секреты
  - base.py — шаблон детекторов
- src/scanner/reporters/ - отображение результатов
  - console.py — вывод в терминал с цветами (через rich)
  - json.py — вывод в JSON для интеграции с другими системами (SARIF, GitLab SAST)

src/scanner/main.py - точка входа
